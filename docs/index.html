REA + VS Code + Cline

A free reverse-engineering assistant for low-resource computers. No credit card. Free software spirit. Un asistente gratuito de ingeniería inversa para computadoras de bajos recursos. Sin tarjeta. Espíritu de software libre.

What this isQué es esto

A step-by-step guide to install REA — an MCP server with 207 reverse-engineering tools — inside VS Code with the Cline agent, powered by Google's free Gemini API. Tested on a real low-end laptop: Debian 13, 4 GB RAM. Una guía paso a paso para instalar REA — un servidor MCP con 207 herramientas de ingeniería inversa — dentro de VS Code con el agente Cline, usando la API gratuita de Gemini de Google. Probado en una laptop modesta de verdad: Debian 13, 4 GB de RAM.

One rule that saves you an hour: always use a Flash model, never a Pro model. The free API key does not allow Pro models. Una regla que te ahorrará una hora: usa siempre un modelo Flash, nunca un modelo Pro. La API key gratuita no permite modelos Pro.

StepsPasos

1 — Install VS Code1 — Instalar VS Code

Run in a terminal:Ejecuta en una terminal:

wget -O /tmp/vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64" && sudo dpkg -i /tmp/vscode.deb; sudo apt-get install -f -y

You should see: lines ending with Setting up code (1.142.0...), and which code prints /usr/bin/code.Deberías ver: líneas que terminan en Setting up code (1.142.0...), y which code imprime /usr/bin/code.

Then delete the 229 MB installer you no longer need:Luego borra el instalador de 229 MB que ya no necesitas:

rm -f /tmp/vscode.deb

2 — Install Cline2 — Instalar Cline

code --install-extension saoudrizwan.claude-dev

You should see: Extension 'saoudrizwan.claude-dev' v4.1.25 was successfully installed.Deberías ver: Extension 'saoudrizwan.claude-dev' v4.1.25 was successfully installed.

3 — Connect your free Gemini key3 — Conectar tu key gratuita de Gemini

  1. In VS Code, click the Cline icon in the left sidebar, then the gear (settings).En VS Code, haz clic en el icono de Cline en la barra lateral, luego en el engranaje (ajustes).
  2. Set API Provider to Google Gemini.Pon API Provider en Google Gemini.
  3. Get your free key at aistudio.google.com/apikey and paste it.Obtén tu key gratuita en aistudio.google.com/apikey y pégala.
  4. Set Model to gemini-2.5-flash.Pon Model en gemini-2.5-flash.

You should see: gemini:gemini-2.5-flash at the bottom of the Cline panel.Deberías ver: gemini:gemini-2.5-flash abajo del panel de Cline.

IMPORTANT — Flash, not ProIMPORTANTE — Flash, no Pro Picking a Pro model makes every request fail with 400 INVALID_ARGUMENT. The free key only allows Flash models. Elegir un modelo Pro hace que cada petición falle con 400 INVALID_ARGUMENT. La key gratuita solo permite modelos Flash.

4 — Plug in REA (the 207 tools)4 — Enchufar REA (las 207 herramientas)

Cline 4.x reads MCP servers from exactly this file:Cline 4.x lee los servidores MCP de exactamente este archivo:

~/.cline/data/settings/cline_mcp_settings.json

cat > ~/.cline/data/settings/cline_mcp_settings.json << 'EOF'
{
  "mcpServers": {
    "rea": {
      "command": "npx",
      "args": ["-y", "rea-agents@6.5.0", "mcp"],
      "disabled": false,
      "autoApprove": []
    }
  }
}
EOF
WARNING — why not AntigravityAVISO — por qué no Antigravity Google Antigravity caps MCP servers at 100 tools; REA exposes 207. That is why this guide uses Cline. Google Antigravity topa los servidores MCP en 100 herramientas; REA expone 207. Por eso esta guía usa Cline.

5 — Reload and verify5 — Recargar y verificar

  1. Press Ctrl+Shift+P, type Reload Window, press Enter.Pulsa Ctrl+Shift+P, escribe Reload Window, pulsa Enter.
  2. In the Cline panel, click the MCP servers icon.En el panel de Cline, haz clic en el icono de servidores MCP.
  3. rea appears with a green dot. Click it to expand: Tools (207).rea aparece con un punto verde. Haz clic para expandirlo: Tools (207).
NOTE — RAMNOTA — RAM With 4 GB of RAM, close your browser while using VS Code + Cline. One heavy app at a time. Con 4 GB de RAM, cierra tu navegador mientras usas VS Code + Cline. Una app pesada a la vez.
